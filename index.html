📍 iPad-finder

Denne fil kan ikke åbnes direkte. Start i stedet programmet:

  • Windows: dobbeltklik på start-windows.bat
  • Mac: højreklik på start-mac.command og vælg Åbn
  • Linux: kør ./start-linux.sh

Så åbner iPad-finder af sig selv i din browser. Se README.md for mere hjælp.

Åbn web-appen (kun når siden ligger på en webserver).
